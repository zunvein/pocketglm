First alpha. The proof of concept now works end to end on a phone: start the bridge, farm tokens, chat.

## New in the app

- **Five tabs with dark mode:** Home, Chat, API, Accounts, Logs. Light or dark follows the system.
- **Home:** bridge status, device token count (turns yellow when low), chats answered and failed, pool age.
- **Chat:** a small test box with a model picker. Replies stream in, including the model's reasoning. Each reply uses one device token.
- **API:** endpoints for this phone and for your Wi-Fi, an API key that is hidden until you tap Show, copy, new key, custom key, a ready curl example and a test button.
- **Accounts:** sign in to Z.AI inside the app, or paste a token. Tokens are stored encrypted with the Android Keystore. You can reveal the email of each account, and copy the full token to paste again after a reinstall. Several accounts are rotated per request.
- **First-run setup:** choose your account, paste a saved token, or continue as a guest.
- **Copy all logs** hides API keys and account tokens.

## Tokens

- **Batch mint:** one WebView visit now adds about 61 device tokens instead of 1. The bridge checks the batch against Aliyun first and drops it if it is refused.
- **Auto top-up:** while the app is open and the pool is at 3 or less, the farm opens by itself. It waits 2 minutes after a success and 10 minutes after a failure.
- **Background farm (experimental, off by default):** farms with a hidden browser while the bridge runs, even with the app closed. After two failures in a row it notifies you.

## Keeping it running

- A wake lock and a Wi-Fi lock while the bridge runs, so other devices on the network can reach it with the screen off.
- A button to allow unrestricted battery use.
- The bridge starts again by itself if Android stops the service, unless you pressed Stop.

## Bridge fixes

- New `POST /admin/mint` endpoint (same API key) behind the batch mint.
- Fixed a race that could report `tokenCount: -1` for a healthy database.
- The startup banner no longer prints the full API key.
- Login: Google and GitHub pages now stay inside the app instead of opening your default browser, and the app only reads the token after you tap **I am signed in**. Guest tokens are refused.

## Known limits

- Alpha. Expect bugs, and please report them with the output of **Copy all logs**.
- The background farm and the wake lock depend on how your phone's maker handles background apps.
- Google sign-in may be refused by Google inside an app. Use email or GitHub.
- Guests only reach the flash models.
- arm64 only, Android 8 or newer.
