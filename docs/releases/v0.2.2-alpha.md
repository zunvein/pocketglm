# v0.2.2-alpha

Bridge fixes ported from the desktop build, plus a health fix.

## Fixed
- **`/health` no longer reports down after an account rotation.** When Z.AI
  answered "Model is currently at capacity" and the bridge switched to its
  next configured account, `/health` returned 503 until the next request
  re-initialised the session. With configured tokens the bridge now reports
  healthy.
- **Token count race.** `/health` could briefly return `tokenCount: -1` while
  the database was fine. The freshness check and the value read now share one
  lock.
- **API key in the startup banner is masked** (`sk-pgl-...nue`), so copying
  the logs no longer leaks the full key.

## Also
- Aliyun captcha settings can be overridden by environment variables on the
  desktop build. Defaults are unchanged.

Same as v0.2.1-alpha.
