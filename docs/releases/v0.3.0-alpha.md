# v0.3.0-alpha

Adds a **public link**, so a friend can reach your bridge from outside your Wi-Fi.

## New
- **Public link (API tab).** The bridge embeds the ngrok agent (ngrok-go), so the
  APK needs no extra binary (about +2.5 MB). Open the API tab, tap *Set up*, paste
  your ngrok authtoken, and optionally your free static domain
  (`name.ngrok-free.app`) so the address stays the same after a restart. The card
  shows the state (Online, Connecting, Failed), the link, and a *Copy link*
  button. A switch turns it on and off.
- The authtoken is encrypted with the Android Keystore (AES-256-GCM), handed to
  the bridge only through its environment, and is never logged or shown back.
- New bridge endpoints `/admin/tunnel/status|start|stop` (API key required). With
  no authtoken the whole feature stays inert.

## Fixed
- Accounts tab: the expiry line no longer touches the Copy token / Remove buttons.
- Chat tab: it no longer refuses to send while the bridge is warming up.

## Changed
- Account encryption code moved into a shared helper. Same key alias, so saved
  accounts keep working.

## Known limits
- Not tested with a real ngrok account yet. ngrok's free plan allows one static
  domain, 1 GB and 20,000 requests per month.
- Anyone who has the link AND your API key can spend your Z.AI accounts and device
  tokens. Share the key only on purpose. Separate keys per person are not built yet.
- The link only stays up while the phone is awake and online.
- Does not fix the blocking of chat.z.ai on some networks (Token Farm still needs a
  working route to chat.z.ai).
