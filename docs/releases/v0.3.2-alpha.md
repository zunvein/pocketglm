# v0.3.2-alpha

Setup, login and farm fixes from owner testing, plus easier sharing of logs.

## New
- **Reset token pool** (Home tab, under the farm card). Deletes every device token
  and restarts the bridge with an empty pool. Accounts and the API key stay.
- **Share full log** (Logs tab). Hands the whole `bridge.log` to the share sheet as
  a file, with secrets hidden and no line cut. "Copy all logs" is still there.
- **Reload** on the Token Farm screen starts a fresh run, and on the sign-in screen
  it reloads chat.z.ai.
- **Thinking folds by default.** Tap "Thinking" in a reply to show it.

## Changed
- A successful farm closes its screen by itself, whether you opened it or the
  auto top-up did.
- Setup text no longer says Google often refuses sign-in.

## Known limits
- Batches added as "not fully verified (inconclusive)" are kept in the pool. Some of
  those tokens may be bad, which shows up later as `captcha generation returned
  empty payload` in chat.
- Minted batches are still rejected when the template slot 87 is not the server
  timestamp on some phones (`slot 87 is not the server timestamp`).
