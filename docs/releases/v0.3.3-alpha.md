# v0.3.3-alpha

Layout and logging fixes from owner testing.

## Changed
- **Compact buttons in corners and headers.** Reload on the Token Farm and sign-in
  screens is now a small button in the top-right corner.
- **Logs tab:** Share full log and Copy all logs sit side by side.
- **Token Farm screen:** Copy log and Share log sit at the bottom, side by side.
  Every farm line is also written to bridge.log, so a run that closes on success
  can still be read from the Logs tab.
- **Bridge startup banner** is one box with aligned rows and the masked API key.

## Fixed
- Browser clients may send `ngrok-skip-browser-warning` (CORS allow-list), so they
  get past the ngrok interstitial page.

## Not in this release yet
- One API key per friend, with revoke, and a request limit per key.
- Farm failures on blocked networks are still open (see the v0.3.1 bypass switch).
