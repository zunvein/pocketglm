# v0.3.4-alpha

Friend keys, a stricter batch check, and Logs buttons moved to the bottom.

## New
- **Friend keys (API tab).** Make one key per person with *New friend key*, copy it
  to them, and revoke it any time. A friend key can use the chat API only: admin and
  maintenance routes answer 403. Each friend key is limited to 60 requests a minute
  and gets 429 when it goes over. Your own key is never limited.
- Friend keys are redacted in the logs and in any text the app shows or copies.
- Changing friend keys restarts the bridge, like changing the key does.

## Changed
- **Unconfirmed mint batches are dropped.** When Aliyun does not confirm a minted
  batch (inconclusive), the batch is no longer added to the pool. The browser's own
  token is still added. This means fewer tokens per farm run, but no more unknown
  tokens that fail later with `captcha generation returned empty payload`.
- **Logs tab:** Share full log and Copy all logs now sit at the bottom of the log.

## Known limits
- Friend keys are not stored on the VPS. They only exist on your phone and in the
  bridge's environment. The 60/minute limit is per bridge process.
- Bypass blocking did not help on mobile data for the owner. It stays off by default.
