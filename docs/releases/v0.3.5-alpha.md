# v0.3.5-alpha

Each friend key now has its own request limit.

## New
- **Limit button on every friend key** (API tab → Friend keys). Set how many requests
  a minute that key may make, from 1 to 1000. The default is 60. The card shows the
  current limit under the key.
- Changing a limit restarts the bridge, like the other friend key changes.

## Fixed
- Friend keys were limited to 60 a minute with no way to change it. Now each key has
  its own number.

## Known limits
- Limits are counted per bridge process, so they reset when the bridge restarts.
- The owner key is never limited.
