# PocketGLM v0.3.8-alpha: new shell, same bridge

The app was rebuilt around the PocketSeek layout: five destinations, one card
language, one type scale, and warm-paper light plus a matched dark theme.

## What changed on screen

- **Home** answers the three questions in order: bridge state with the pool
  size as the one big number, answered and failed chats side by side, then the
  addresses (`127.0.0.1` and the Wi-Fi one) where a tap copies. The farm
  controls (farm now, auto top-up, background farm, reset pool) and the phone's
  battery settings follow.
- **Stats** is the old Logs tab with the numbers attached: pool size, answered,
  failed, pool age, breaker state, and the tail of bridge.log plus Reload, Copy
  and Share (secrets are redacted before anything leaves the app).
- **Accounts** keeps the Z.AI rows (active or expired pill, masked token, expiry,
  reveal the address) with sign-in and paste as the two ways in.
- **Chat** is the end-to-end test box, moved to plain views so it matches the
  rest of the app: model picker, streaming answer, folded reasoning.
- **Settings** holds the API key (show, copy, new, custom), the ngrok public
  link, friend keys with their per-key limit, the blocked-network bypass, and a
  crash log you can read or copy without adb.

## Under the hood

- The shell, the screens and the app theme are plain framework views
  (`android:Theme.DeviceDefault`), so the old AppCompat activity base is gone
  from the main, setup, farm and sign-in screens.
- `Ui.kt` is the whole design system: tokens, cards, tiles, pills, buttons,
  switches, inputs, dialogs and the two motion helpers. A new screen is one file
  that extends `Screen` and returns a column of cards.
- **CrashLog** now exists in this app too: an uncaught exception is written to
  `files/bridge/crash-last.log` and shown in Settings, which is how a crash on
  the phone gets diagnosed without a cable.
- The notification permission is requested when the bridge is first started
  instead of at launch.

## Unchanged

The Go bridge, the token farm, minting, account storage, the API key and friend
key formats, and every endpoint. This release only changes what you see.
